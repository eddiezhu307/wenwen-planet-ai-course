# 问问星球

面向中国家庭与 8-15 岁孩子的 AI 启蒙课程网站。

## 在线内容

- 首页课程世界观与 16 节课地图
- 独立互动课堂页面
- 每课交互 PPT、小游戏、Prompt 模板和家庭任务
- 使用中国大陆可直接访问的 AI 工具作为案例

## 本地预览

```bash
python3 -m http.server 4173
```

打开：

```text
http://127.0.0.1:4173/index.html
```

## 主要文件

- `index.html`：课程官网首页
- `course.html`：独立互动课堂
- `script.js`：课程数据、交互 PPT 和小游戏逻辑
- `styles.css`：基础样式
- `wenwen-bright.css`：问问星球高饱和插画风格覆盖样式
- `AI时代家庭成长课（中国版）教学大纲参考.md`：课程大纲参考文档
